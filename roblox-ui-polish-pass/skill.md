\## UI quality standards

Target a polished Roblox UI that is:

\- consistent

\- readable

\- responsive

\- visually coherent

\- not cluttered

\- not cheap-looking

\- easy to navigate

\- free of dead buttons and stale states

\- free of overlapping or broken panels



\## Required checks

Validate:

\- all buttons work

\- all primary panels open/close correctly

\- no dead navigation paths

\- no duplicated panels

\- no invisible-but-active UI intercepting input

\- no stale data after transitions

\- no broken scoreboards

\- no broken results screens

\- no missing text or icons where required

\- no visually inconsistent spacing/typography/hierarchy



\## Presentation priorities

Improve:

1\. Readability

2\. Hierarchy

3\. Spacing and alignment

4\. State transitions

5\. Hover/press/focus feedback

6\. Empty state handling

7\. Panel consistency

8\. Color use and contrast

9\. Premium feel



\## Execution flow

\### Pass 1: Audit

\- identify broken or weak UI surfaces

\- identify stale state issues

\- identify inconsistent theme/layout issues



\### Pass 2: Functional fixes

\- fix broken buttons

\- fix dead screens

\- fix stale state

\- fix bad transitions

\- fix miswired menu flows



\### Pass 3: Visual polish

\- improve spacing

\- improve typography

\- improve hierarchy

\- improve transitions and responsiveness

\- improve title/lobby/HUD/results presentation



\### Pass 4: Final UX validation

\- retest full menu navigation

\- retest mode and results flow

\- confirm UI no longer feels unfinished



\## Output expectations

Summarize:

\- files modified

\- broken flows fixed

\- visual improvements made

\- remaining weak spots if any



\## Success condition

This skill succeeds when the UI feels cohesive, readable, responsive, and polished, with no major broken states or cheap-looking presentation left.
