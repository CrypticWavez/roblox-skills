\# Roblox Simulator Progression Pass



\## Purpose

Use this skill for simulator games built around repeatable actions, currencies, upgrades, unlocks, zones, pets, multipliers, and long-term progression.



This skill focuses on:

\- core earn loop

\- currencies and multipliers

\- unlock pacing

\- pets/companions if present

\- zone progression

\- rebirth or reset loops

\- progression UI clarity

\- save/load integrity



\## When to use

Use this skill when the user wants to:

\- improve a simulator

\- fix progression

\- improve pacing

\- harden save/reward logic

\- improve pets/upgrades/zones



\## Core behavior

Audit:

\- core action loop

\- currencies

\- multipliers

\- upgrade systems

\- pet or companion logic

\- zone unlocks

\- rebirth loops

\- persistence

\- progression UI



Then improve the highest-value pacing and integrity issues.



\## Quality standards

Simulator progression should be:

\- understandable

\- addictive without being broken

\- paced clearly

\- resistant to duplication

\- persistent and safe

\- easy to read in UI



\## Required checks

Validate:

\- core earn loop

\- spend loop

\- upgrade effects

\- pet/companion effects if applicable

\- zone unlocks

\- rebirth logic

\- no broken multiplier stacking

\- no duplicate rewards

\- no broken save/load states



\## Execution flow

\### Pass 1: Audit

\- identify pacing and integrity issues



\### Pass 2: Logic fixes

\- fix progression math and reward logic

\- fix persistence and stacking bugs



\### Pass 3: UX and pacing polish

\- improve progression surfaces

\- improve clarity and retention hooks



\### Pass 4: Final validation

\- retest long-term loop integrity



\## Success condition

This skill succeeds when simulator progression is coherent, satisfying, and resistant to obvious integrity failures.
