# AVKit

Audio and visual effects as data: the vfx/1 preset format with a neutral library and pooling, and the audio-graph/1 mixer (buses, cues, ducking, music scheduling) on the Audio API. Pure validators and plans run in Lune; `*Roblox.luau` adapters build the Instances.

Owner: G5 (look, sound and feel). Contract, tiers and the planned module list: [docs/runtime-kits.md](../../docs/runtime-kits.md). Empty until G5 merges; this README keeps the folder in git and Rojo builds it as an empty Folder.
