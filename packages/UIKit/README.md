# UIKit

Neutral UI kit: tokens, styles, breakpoints, state, transitions and easing, navigation and focus, localisation, audits and about 25 components, with a gallery. Plain Instances, no framework; pure plans run in Lune and `*Roblox.luau` adapters touch the engine. No production UI is designed here.

Owner: G4 (UI kit and cinematics). Contract, tiers and the planned module list: [docs/runtime-kits.md](../../docs/runtime-kits.md). Empty until G4 merges; this README keeps the folder in git and Rojo builds it as an empty Folder.
