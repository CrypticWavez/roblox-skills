\# Roblox TestEZ Test Author Pass



\## Purpose

Use this skill when a Roblox repo needs better automated test coverage for logic-heavy systems.



This skill focuses on:

\- identifying testable logic

\- adding focused TestEZ coverage

\- protecting high-risk utility and systems math

\- improving confidence before release



\## When to use

Use this skill when the user wants to:

\- add tests

\- improve validation

\- protect gameplay math

\- verify reward/rank/helper logic



\## Core behavior

Audit:

\- existing test coverage

\- Wally/TestEZ setup

\- pure logic modules

\- calculation-heavy systems

\- reward and progression helpers

\- queue/team/rank utilities



Then add targeted tests where they provide the most value.



\## Quality standards

Tests should:

\- target deterministic logic

\- avoid fragile unnecessary coupling

\- protect high-risk behavior

\- be readable and focused



\## Required checks

Prefer tests for:

\- damage math

\- reward math

\- rank/MMR calculations

\- queue/team helpers

\- inventory/loadout validators

\- utility transforms

\- progression thresholds



\## Execution flow

\### Pass 1: Audit

\- identify best candidates for automated tests



\### Pass 2: Add tests

\- add focused specs

\- improve test organization

\- avoid low-value noisy tests



\### Pass 3: Validation

\- ensure tests match real module behavior

\- update tests if behavior intentionally changed



\## Success condition

This skill succeeds when the repo has stronger automated protection for high-risk logic.
