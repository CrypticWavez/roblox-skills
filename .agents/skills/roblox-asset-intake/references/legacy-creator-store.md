# Roblox Creator Store Asset Integration Pass

## Purpose

Use this skill when the game needs better art support, props, sounds, icons, or presentational assets sourced from Roblox asset ecosystems.

This skill focuses on:

- curated asset selection
- style cohesion
- map dressing
- UI asset sourcing
- weapon/player prop enhancement
- sound sourcing
- clean integration into repo workflows

## When to use

Use this skill when the user wants:

- better visuals
- better props
- better sounds
- better icons/thumbnails
- stronger presentation from sourced assets

## Core behavior

Audit:

- current visual style
- weak or placeholder-feeling assets
- missing support assets
- technical integration needs
- asset usage paths in code and hierarchy

Then source and integrate only what materially improves quality.

## Quality standards

Asset integration should:

- fit the art direction
- avoid obvious mismatch
- avoid bloated junk imports
- remain maintainable
- support gameplay readability
- avoid breaking the repo structure

## Required checks

Validate:

- assets fit the intended style
- no unnecessary or duplicate assets are introduced
- references are wired safely
- no critical flow depends on an unconfirmed asset
- sound/visual assets do not damage readability or performance

## Execution flow

### Pass 1: Audit

- identify weak asset areas
- identify what should be sourced or replaced

### Pass 2: Asset integration

- integrate curated assets
- wire references cleanly
- update configs/usages

### Pass 3: Polish and validation

- confirm assets improve the experience
- confirm maintainability and consistency

## Output expectations

Summarize:

- assets integrated or replaced
- code/config changes made
- style improvements achieved
- remaining weak spots if any

## Success condition

This skill succeeds when sourced assets materially improve quality without making the project messy or visually inconsistent.
