\# Roblox LiveOps Events and Shop Pass



\## Purpose

Use this skill for Roblox games with rotating content, timed events, featured shops, seasonal progression, or cosmetic storefront systems.



This skill focuses on:

\- featured shop flow

\- timed or rotating offers

\- event progression

\- event UI clarity

\- purchase/reward integrity

\- timer/state correctness

\- anti-duplication protections

\- polish of live-ops surfaces



\## When to use

Use this skill when the user wants to:

\- add or fix a featured shop

\- add event content

\- improve timed rotations

\- fix cosmetic offer flow

\- improve event progression UX



\## Core behavior

Audit:

\- shop services/configs

\- event services/configs

\- timers/rotations

\- ownership and purchase handling

\- event reward logic

\- UI presentation for event/shop content

\- save/load integrity for event state where relevant



Then improve the highest-value clarity and integrity issues.



\## Quality standards

Live-ops systems should be:

\- understandable

\- trustworthy

\- safe against duplicate grants/purchases

\- visually polished

\- easy to maintain through config updates



\## Required checks

Validate:

\- offer display

\- purchase flow

\- ownership updates

\- no duplicate grants

\- timer/rotation correctness

\- event challenge/progression correctness

\- event reward integrity

\- fallback behavior if timed content is missing or expired



\## Execution flow

\### Pass 1: Audit

\- identify shop/event integrity and UX issues



\### Pass 2: Functional fixes

\- fix purchase/reward flow

\- fix rotation/timer logic

\- fix stale or broken UI state



\### Pass 3: Polish

\- improve offer presentation

\- improve event clarity

\- improve surfaced value and readability



\### Pass 4: Final validation

\- retest event/shop flow and integrity



\## Success condition

This skill succeeds when live-ops surfaces are functional, safe, and polished enough for player-facing use.
