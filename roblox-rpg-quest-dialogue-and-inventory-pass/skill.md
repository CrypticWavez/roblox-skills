\# Roblox RPG Quest Dialogue and Inventory Pass



\## Purpose

Use this skill for RPG or adventure games with quests, dialogue, NPC interactions, inventory, rewards, and progression gating.



This skill focuses on:

\- quest state

\- dialogue flow

\- NPC interaction logic

\- inventory ownership and integrity

\- item rewards

\- progression gating

\- save/load continuity

\- UX clarity around objectives



\## When to use

Use this skill when the user wants to:

\- build or fix quests

\- fix dialogue

\- improve inventory

\- stabilize item rewards

\- improve RPG progression



\## Core behavior

Audit:

\- quest services/data

\- NPC interaction flow

\- dialogue UI/state

\- inventory modules

\- item reward logic

\- save/load of quest and inventory state

\- objective tracking UI



Then fix broken progression and clarity issues.



\## Quality standards

RPG progression should be:

\- understandable

\- persistent

\- resistant to item duplication/loss

\- smooth through quest transitions

\- clear in player objectives



\## Required checks

Validate:

\- quest start

\- quest objective progress

\- quest completion

\- dialogue branches if present

\- inventory add/remove/equip if applicable

\- item reward integrity

\- save/load continuity

\- no duplicate quest rewards

\- no blocked progression from stale quest state



\## Execution flow

\### Pass 1: Audit

\- identify quest/dialogue/inventory blockers



\### Pass 2: Logic fixes

\- fix quest progression

\- fix dialogue flow

\- fix inventory integrity and reward logic



\### Pass 3: UX polish

\- improve objective clarity

\- improve dialogue and quest presentation



\### Pass 4: Final validation

\- retest progression chain and save/load



\## Success condition

This skill succeeds when quests, dialogue, and inventory are coherent, persistent, and progression-safe.
