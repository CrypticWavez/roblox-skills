# UX flows

Status: TBD

Prompts only. Screens use the UI kit once it is installed; flows are checked in Device Simulator on
every declared device (release item S04) and with reduced motion on (release check A07).

## Screen map
> Prompt: Every screen and overlay, and how a player moves between them (a list or a diagram).

## First-time flow
> Prompt: From the loading screen to the first meaningful action. Which onboarding step does each screen complete?

## Input
> Prompt: Input Action System contexts and actions per screen (Config `input.contexts`), on touch, gamepad and keyboard and mouse.

## Feedback and states
> Prompt: Loading, empty, error, offline and reconnect states for each screen.

## Accessibility
> Prompt: Text size and contrast, reduced motion, flashes, subtitles, colour-blind modes, touch target size.

## Localisation
> Prompt: Which strings are dynamic, where text may grow (pseudo-locale), and the source locale.

## Store and prompts
> Prompt: Where purchase prompts appear and what the player sees before each (odds for paid random items).
