# {{NAME}}

Roblox game repository created by the factory project starter. Agents and people start with `AGENTS.md`; game-design decisions are logged in `docs/decisions.md`.

```
rokit install                                   # rojo, lune, stylua, selene, luau-lsp at the factory's pins
python3 tools/check.py                          # StyLua, JSON, secrets, skills, hooks, Selene, Lune specs, Rojo build
rojo build default.project.json -o build/game.rbxl
rojo serve default.project.json                 # live sync into an unpublished test place
```
