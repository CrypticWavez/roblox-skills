# Roblox Title and Lobby Polish Pass

## Purpose

Use this skill when the front-end of a Roblox game feels cheap, empty, broken, or unfinished.

This skill focuses on:

- title screen
- main menu
- lobby scene
- menu transitions
- profile entry points
- queue/mode cards
- atmosphere and scene dressing
- front-end audio and feedback
- first-impression quality

## When to use

Use this skill when the user asks to:

- improve title screen
- improve lobby
- make the game look more polished
- clean up first-time player experience
- fix lobby/menu flow

## Core behavior

Start by auditing:

- title menu UI
- lobby UI and scene
- menu navigation
- mode selection
- transitions
- camera flow if present
- front-end sounds
- profile/stats/queue access points

Then improve both function and presentation.

## Quality standards

The front-end should be:

- visually appealing
- easy to navigate
- coherent with the game’s genre
- responsive
- not empty or placeholder-feeling
- free of broken menu states

## Required checks

Validate:

- title buttons work
- menu navigation works
- queue or play entry points work
- settings/profile/loadout entry points work
- lobby UI reflects player state correctly
- transitions are not broken
- no stale or hidden panels remain active
- lobby scene supports the game fantasy

## Execution flow

### Pass 1: Audit

- identify broken front-end flow
- identify weak presentation and atmosphere

### Pass 2: Functional fixes

- fix menu routing
- fix broken entry points
- fix stale front-end state

### Pass 3: Presentation pass

- improve scene composition
- improve camera/transition flow
- improve visual hierarchy and polish
- improve audio/feedback if applicable

### Pass 4: Final validation

- retest title -> lobby -> next action flow

## Output expectations

Summarize:

- files modified
- front-end flow fixes
- visual improvements
- remaining weak spots if any

## Success condition

This skill succeeds when the title screen and lobby feel coherent, polished, and ready to serve as the game’s front door.
