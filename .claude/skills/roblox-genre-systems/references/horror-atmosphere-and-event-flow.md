# Roblox Horror Atmosphere and Event Flow Pass

## Purpose

Use this skill for horror games where atmosphere, event pacing, readability, and objective flow are more important than raw combat complexity.

This skill focuses on:

- event triggers
- environmental atmosphere
- objective flow
- scare timing
- audio and lighting presentation
- chase or fail-state transitions
- progression clarity without ruining tension

## When to use

Use this skill when the user wants to:

- improve horror mood
- fix event flow
- polish scares
- improve horror objectives
- make the game feel more immersive

## Core behavior

Audit:

- event sequences
- trigger logic
- objective progression
- audio and lighting usage
- fail/chase/recovery flow
- player guidance and confusion points

Then improve both atmosphere and reliability.

## Quality standards

Horror flow should be:

- tense
- readable enough to progress
- free of broken triggers
- free of cheap confusion from bugs
- strong in atmosphere and pacing

## Required checks

Validate:

- event triggers fire correctly
- no critical sequence blockers remain
- objective progression is understandable
- atmosphere enhancements do not obscure gameplay-critical information
- fail-state recovery works
- audio/lighting improves tension without breaking readability

## Execution flow

### Pass 1: Audit

- identify broken triggers and weak atmosphere areas

### Pass 2: Functional fixes

- fix sequence/event progression
- fix objective blockers
- fix fail/recovery issues

### Pass 3: Atmosphere pass

- improve audio, lighting, mood, and pacing

### Pass 4: Final validation

- retest complete event flow

## Success condition

This skill succeeds when the horror experience is atmospheric, readable, and not undermined by broken event logic.
