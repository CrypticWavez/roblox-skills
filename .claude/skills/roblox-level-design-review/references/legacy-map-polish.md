## Core behavior

Start by auditing every live map used by the game.

Inspect:

- map themes

- cover placement

- sightlines

- spawn placement

- routeing/navigation

- objective placement if applicable

- dead zones

- unfair angles

- prop density

- lighting

- VFX/atmosphere

- map identity and coherence

Then make a concise plan and improve the worst gameplay and visual issues first.

## Map quality standards

Maps should be:

- readable

- fair enough for intended mode

- visually coherent

- not empty-feeling

- not cluttered

- strong in identity

- supportive of the game’s core combat loop

- free of obvious spawn abuse, softlocks, and dead routes

## Required checks

Validate:

- spawn safety/fairness

- route clarity

- no broken traversal

- no visual confusion in key combat spaces

- cover density supports the intended combat pacing

- dead space is reduced or intentional

- lighting supports readability

- maps no longer feel placeholder-heavy or ugly

## Execution flow

### Pass 1: Audit

- identify weak maps and weak zones

- identify fairness and readability issues

- identify visual quality gaps

### Pass 2: Gameplay fixes

- improve spawns

- improve cover/sightlines

- improve routes and combat spaces

- remove dead/cheesy/problematic areas

### Pass 3: Visual polish

- improve dressing

- improve lighting

- improve atmosphere

- improve identity and composition

### Pass 4: Final validation

- retest maps for gameplay and presentation quality

- confirm they feel intentional and ship-worthy

## Output expectations

Summarize:

- maps improved

- gameplay/fairness issues fixed

- visual improvements made

- remaining weak spaces if any

## Success condition

This skill succeeds when the game’s maps are readable, fair, visually cohesive, and no longer feel empty, ugly, or placeholder-heavy.
